# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-03-13

### Added

- Initial release of `react-easy-google-map`.
- `GoogleMap` component for easy rendering of Google Maps with multiple markers.
- Built-in `InfoWindow` support for data pins.
- Customizable `Pin` styles (background color, border, glyph color, scale).
- Support for Advanced Markers via `@vis.gl/react-google-maps`.
- Comprehensive TypeScript support.
- English and Japanese documentation (README).
- Multi-format build output (CJS, ESM) using `tsup`.
